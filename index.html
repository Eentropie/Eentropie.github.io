Featured publication Preprint · April 2026

Co-first author

BRASP: Boolean Range Queries over Encrypted Spatial Data with Access and Search Pattern Privacy

Jing Zhang, Ganxuan Yang, Yifei Yang, Siqi Wen, Zhengyang Qiu

BRASP is a dual-server searchable-encryption system for Boolean spatial range queries. It combines Hilbert-curve prefix encoding, encrypted indexes, index shuffling, and ID redistribution to protect both search and access patterns while supporting updates.
